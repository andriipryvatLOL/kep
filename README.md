# Простий сайт

Супер простий навчальний сайт на HTML, CSS та JavaScript.

## Структура

- `index.html` — головна сторінка
- `about.html` — сторінка «Про сайт»
- `contact.html` — сторінка контактів
- `assets/css/style.css` — стилі
- `assets/js/main.js` — JavaScript
- `assets/images/icons/` — папка для іконок
- `assets/fonts/` — папка для шрифтів

## Запуск

Відкрийте файл `index.html` у браузері.
